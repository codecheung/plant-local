# 快速开始（后端 V1）

## 1. 启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.app.main:app --reload
```

接口文档：`http://127.0.0.1:8000/docs`
控制台页面：`http://127.0.0.1:8000/`

## 2. 流程示例

### 2.1 导入图片

`POST /api/data/import`

```json
{
  "source_dir": "/absolute/path/to/images",
  "copy_to_raw": true,
  "extensions": [".jpg", ".jpeg", ".png", ".webp"]
}
```

或使用文件上传（推荐，适合浏览器操作）：

`POST /api/data/upload-files`（`multipart/form-data`，字段名 `files`，支持多文件）

### 2.2 保存标注

`POST /api/label/save`

```json
{
  "items": [
    { "image_id": 1, "label": "target_plant", "reviewed": true },
    { "image_id": 2, "label": "other", "reviewed": true }
  ]
}
```

撤销最近 N 次标注操作：

`POST /api/label/undo`

```json
{
  "steps": 1
}
```

查看最近标注操作日志：

`GET /api/label/operations?limit=20`

### 2.2.1 查询图片与标注进度

- 图片分页：`GET /api/images?page=1&page_size=20`
- 随机待标注抽样：`GET /api/images/random-unlabeled?count=20`
- 标注统计：`GET /api/labels/stats`

### 2.3 启动训练

`POST /api/train/start`

```json
{
  "mode": "new"
}
```

查看状态：`GET /api/train/{job_id}`

### 2.3.1 启用真实训练（可选）

```bash
pip install -r requirements-ml.txt
export USE_REAL_TRAINING=1
```

真实训练会自动执行样本切分，并导出 ONNX 模型。

### 2.4 启动批量识别

`POST /api/infer/start`

```json
{
  "model_version": "v1",
  "input_dir": "/absolute/path/to/images"
}
```

查看状态：`GET /api/infer/{job_id}`

### 2.5 导出识别结果

- CSV: `GET /api/infer/{job_id}/export?format=csv`
- JSON: `GET /api/infer/{job_id}/export?format=json`
- 复核结果（带 image_id）：`GET /api/infer/{job_id}/results/review`

### 2.6 查看模型版本

`GET /api/model/list`

## 3. 说明

- 当前训练/推理是骨架实现，已打通任务状态与结果导出。
- 后续可在 `backend/app/services.py` 中替换为真实模型训练与推理逻辑。
