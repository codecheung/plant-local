目前这个项目已实现的功能（简版）：

用户登录与会话管理（含主题切换：明/暗模式）
多页面控制台（数据与标注 / 训练与识别 / 模型版本）
本地图片导入（文件/文件夹、去重、入库）
图片列表检索与筛选（关键词、状态、标签、复核、分页）
连续标注模式（键盘快捷标注、上下移动、高亮跟随滚动）
批量标注与批量复核、最近操作撤销
图片预览抽屉（缩放/拖拽/上一张下一张/只看未复核）
标注统计看板与标注操作日志
训练任务管理（新训练 / 继续训练、任务状态轮询、最近任务快捷回查）
识别任务管理（选择模型、启动识别、导出结果）
识别结果复核（按任务加载、按类别筛选、按置信度排序、纠正标签）
模型版本管理（列表、发布状态、指标查看、准确率列展示、用于继续训练/识别快捷操作）
前后端一体化部署（前端构建产物可发布到 backend/app/static）
后端 API 与本地 SQLite 持久化（含数据、任务、模型版本）
