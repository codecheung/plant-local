# plant-local 交付清单（客户移交版）

日期：2026-03-21

## 1. 交付物

### 1.1 代码与目录

- 后端服务：`backend/app/`
- 控制台页面：`backend/app/static/index.html`
- 依赖文件：
  - `requirements.txt`
  - `requirements-ml.txt`（可选，真实训练）
- 运行说明：`README.md`
- 用户手册：`docs/操作手册.md`
- 快速开始：`docs/快速开始.md`

### 1.2 运行时目录（首次启动自动创建）

- `data/`（数据与数据库）
- `models/`（模型版本）
- `outputs/predictions/`（识别结果）
- `logs/`（日志）

## 2. 环境要求

- 操作系统：macOS / Linux（Windows 需自行适配命令）
- Python：3.9+
- 浏览器：Chrome / Edge 最新版

可选（真实训练）：

- GPU 环境（建议）
- PyTorch 依赖可正常安装

## 3. 部署步骤（单机）

在项目根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

访问：

- 控制台：`http://127.0.0.1:8000/`
- 健康检查：`http://127.0.0.1:8000/health`

## 4. 验收走查（建议现场 20-30 分钟）

### 4.1 数据与标注

1. 导入一个样例图片目录
2. 在列表中完成若干条标注与复核
3. 使用批量标注、撤销、随机抽样
4. 打开抽屉进行连续复核（含未复核跳转）

验收点：

- 数据成功导入
- 标注状态与统计正确变化
- 撤销操作可恢复

### 4.2 训练与模型

1. 启动训练任务
2. 查看任务状态至完成
3. 在模型列表确认新版本并发布

验收点：

- 训练任务可启动、可完成
- 模型版本记录可查看、可发布

### 4.3 识别与导出

1. 启动识别任务（单图或目录）
2. 查看状态直到完成
3. 下载 CSV / JSON 结果文件

验收点：

- 识别任务可执行
- 结果可导出、格式正确

## 5. 已知边界（当前版本）

- 默认训练为模拟引擎（用于快速打通业务闭环）
- 真实训练需额外安装 `requirements-ml.txt` 并配置环境变量
- 当前为单机任务执行，不含分布式调度
